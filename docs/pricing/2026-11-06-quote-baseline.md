## 独立发行 API

独立 API 方案不默认包含完整客户发行门户和企业发行平台交付。

| 预付档位 | 月度标准价 | 首期最少 6 个月套餐费 | 半年包含发行次数 |
| --- | ---: | ---: | ---: |
| 起步额度 | ¥999/月 | ¥5,994 | 7,500 |
| 成长额度 | ¥9,999/月 | ¥59,994 | 90,000 |
| 规模额度 | ¥29,999/月 | ¥179,994 | 300,000 |

- 基础 API 接入实施费 ¥9,800，一次性。
- 套餐包含的次数可在半年周期内跨月使用，不是现金充值余额。
- 超出套餐次数后，参考价 ¥1/首/渠道；额外充值或结算方式由合作方案约定。
- 可选扩展模块按每模块 ¥2,000 一次性参考费用测算：资产管理、艺人与厂牌、发行数据、版税报表、分账管理、客户管理 API。接口权限和交付范围按合作方案确认。
- 更新、下架、重传、重复提交、失败任务的计费以正式协议为准。
- Excel、SFTP、XML、DDEX 等专项集成不默认包含在标准 API 实施服务中，单独评估。
