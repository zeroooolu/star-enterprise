FREQUENTLY ASKED QUESTIONS

企业发行合作常见问题

围绕现有系统、品牌运营、历史曲库、发行责任和费用范围，说明企业方案的关键边界。

已经拥有网站或 App，是否需要更换现有系统？

不需要整体更换。可根据现有产品架构评估发行 API 接入，保留账号、界面和主要业务流程；接口范围及联调方式由企业方案确定。

是否可以仅采购发行 API？

可以单独申请发行 API 服务，无须同时采购自有品牌发行门户。API 年费、发行使用费及专项实施费用可在价格页面查看，具体权益以方案为准。

已有大量存量曲库，是否支持迁移？

支持按项目评估历史曲库迁移，包括元数据映射、内容文件整理、批量导入及迁移验证。迁移范围与费用依据数据规模和复杂度确认。

发行审核及渠道交付由哪一方负责？

企业可以开展资料预检及内部运营处理；正式发行审核及渠道交付由看见音乐承担，具体业务责任与异常处理流程以合作协议为准。

可以发行到哪些音乐平台？

可根据业务需求选择中国及全球目标音乐平台。具体发行渠道、内容类型、地区范围与处理规则，以合作开通范围和渠道政策为准。

API 是否包含全部报表和结算接口？

发行 API 以现有真实发行链路为基础，接口能力按阶段逐步完善。数据报表、结算接口、状态回调与技术支持的开放范围需在方案及技术联调阶段确认。

三个版本是否都包含完整发行流程？

包含。三个版本均具备曲库管理、客户发行门户、发行提交、渠道状态、数据与收入报表。版本主要差异在业务容量、合作方分账、系统集成与服务等级。

标准实施费与发行使用费如何计算？

自有品牌发行平台首次开通收取 ¥9,800 标准实施费。版本支持月付或年付；发行使用费为 ¥0.8 / 首 / 渠道，10 首歌曲发行到 6 个渠道的示例使用费为 ¥48。

是否需要购买发行平台才能使用 API？

不需要。基础发行 API 可独立申请，首次接入实施费 ¥9,800（一次性），发行使用费按 ¥0.8 / 首 / 渠道计。其他 API 模块按 ¥2,000 / 模块一次性选购，扩展接口以实际开放进度为准。

基础版和专业版是否能够增购发行 API？

基础版和专业版可按需求增购发行 API；企业版标准包含。实际接口开放范围按开通方案确认。

各版本的视频与合作客户额度是多少？

基础版包含 100 个视频、50 个合作客户；专业版包含 1,000 个视频、1,000 个合作客户；企业版包含 10,000 个视频，合作客户数量按项目配置。具体统计口径以合作方案为准。

超出曲库或客户额度如何处理？

可评估升级版本或单独扩容，具体额度统计及扩容费用在方案阶段确认。

发行更新、重传、下架是否计费？

标准计费单位为一首歌曲向一个目标渠道对应的发行使用量。更新、重传、下架、失败任务等特殊情况以正式商业计费规则为准。

历史曲库迁移与 DDEX 对接是否包含在订阅费内？

套餐包含对应版本标明的系统能力；复杂历史迁移、专项联调及项目级实施按工作范围另行确认。

发行状态查询

基础发行 API 支持按任务 ID、批次路径或作品目录号查询发行处理结果。这些基础状态查询不需要购买独立的发行数据 API；发行数据模块提供产品、渠道和操作历史维度的业务记录。

GET /open/v1/kjson/tasks/{taskId}
GET /open/v1/kjson/tasks?batchPath={batchPath}
GET /open/v1/release/result/latest/{catalogNo}

查询维度适用场景参数来源
taskId已获取任务 ID 时查看任务进度发行任务系统提供的真实 ID
batchPath按已上传并提交的目录定位批次创建任务时使用的批次路径
catalogNo按作品目录号查看 DSP 的最新处理结果K-JSON 作品的目录编号

平台级返回数据可能包含 status、dspId、dspName、platformAlbumId 和 failCode 等字段。调用时应按照实际响应解析可选字段，不要假设失败代码或平台作品 ID 在所有状态下均存在。
