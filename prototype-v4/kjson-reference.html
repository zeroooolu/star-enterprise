K-JSON V0.3.1

K-JSON 是看见发行链路使用的完整发行数据格式，适用于批量发行、大规模曲库迁移和高级系统级对接。本节按原始 V0.3.1 文档完整整理字段、规则、枚举与示例。

如何使用这份结构

标准资源 API 客户通常无需手工拼装整份 K-JSON；系统会根据艺人、专辑、歌曲、文件和发行对象生成底层 K-JSON。需要批量发行或高级系统级接入时，可直接按照本节 V0.3.1 结构生成文件，再通过 STS / OSS / K-JSON 任务链路提交。
